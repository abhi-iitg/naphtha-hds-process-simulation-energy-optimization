# Reference Landscape

These public projects were used only to benchmark project scope and engineering workflow. No external code, numbers, team information, or report text is copied into this repository.

1. Naphtha HDS + heat integration + techno-economic analysis: https://github.com/soham259/Naphtha-Hydrodesulfurization-Aspen-Plus-Simulation-Heat-Integration-Techno-Economic-Optimization
2. Aspen Plus automation and simulation sweeps: https://github.com/zwang1995/Aspen-Plus-Automation
3. Aspen Plus Python interface and optimization: https://github.com/YouMayCallMeJesus/AspenPlus-Python-Interface
4. CSTR/process-control MATLAB projects: https://github.com/topics/cstr?l=matlab
5. Python pinch-analysis reference: https://github.com/anicusan/PyPinch
6. Modular ammonia process design: https://github.com/leonz12345/ChemE_Captone
7. Ammonia equilibrium-process case study: https://github.com/tomarpratham-ctrl/Synthesis-of-Ammonia
8. Chemical plant equipment sizing/costing reference: https://github.com/weepctxb/ChemEngDPpy
9. OpenFOAM CFD platform: https://github.com/OpenFOAM/OpenFOAM-4.x

The strongest design signal across these references is the combination of process fundamentals, simulation, optimization, equipment/energy reasoning, reproducibility, and explicit engineering limitations.
